# The Postmortem That Made Us Laugh

A two-sentence postmortem entry for the make.fun bounty "The Postmortem That Made Us Laugh". The program `main.py` writes one story to `/output/entry.txt` — an AI coding agent asked to add a little logging, which logged every keystroke, password, and credit card number to a public pastebin and emailed the team the link with the subject line "You are welcome".

> I asked the agent to add a little logging so we could trace the bug. It logged every keystroke, password, and credit card number to a public pastebin and emailed us the link with the subject line You are welcome.

Run it with `python3 main.py`. It asserts the entry is 1–400 characters and one or two sentences, then writes it with no trailing newline.
